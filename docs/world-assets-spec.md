# うごかす英語ワールド — イラスト素材の仕様書

このファイルは、ワールドの見た目をさらに高品質にするときに必要な素材の仕様です。
**ここに書いた外部素材(背景画像・キャラクタースプライトなど)は、まだ存在しません。**
現在のワールドは、すべてコードで描いたオリジナルのSVGイラストで動いています。

## 2. さらに品質を上げる場合の方式

SVGのパーツ方式のまま、次のように**層を分けた素材**に置きかえられるようにします。

1. **背景画像**: シーンごとに1枚(遠景)+前景1枚(手前の柱・植物など、人物より手前に描く物)
2. **キャラクタースプライト**: パーツごとに分けた画像(パーツアニメーション用)
3. **小物・設備**: 状態ごとの画像(例: ドア 開/閉、エレベーター 開/閉、レジ 通常/エラー/支払い済み)

置きかえる場所は、`art.js`(人物・小物)と `fixtures.js`(設備・背景)だけです。
当たり判定・座る位置などの座標(`src/world/scenes/*.js`)は、いまの 1000×600 の座標系をそのまま使います。

## 3. 素材の仕様

### 共通
- 座標系: シーン全体 1000×600(表示は横幅に合わせて拡大縮小)
- 形式: SVG を推奨。画像にする場合は WebP(透過あり)、背景は 2000×1200 px(2倍)
- 1シーンあたりの合計サイズの目安: 400KB 以下(スマートフォンでの読み込みのため)
- 色: 輪郭線 `#3b2b2a`、影は元の色を18〜30%暗く。肌・髪の基本色は `src/world/cast.js` の `LK` に合わせる
- 権利: すべてオリジナル、または商用利用・改変が許可された素材に限る。既存の作品のキャラクター・ロゴに似せない

### 人物スプライト(1人分)
- 原点: 足元の中心。右向きで作る(左向きは反転して使う)
- パーツ: 後ろ髪 / 後ろの腕 / 脚(左右)/ 胴体 / 前の腕(ひじで2分割)/ 頭 / 顔 / 前髪
- 顔: 目7種(表情に対応)+ 口3種(閉じ・半開き・開き)
- 歩行: 脚・腕の角度を4コマ(または回転で表現)
- 座り: 腰の高さ 40(いす)/ 12(床)の2種
- 大人の身長: 約190(頭頂まで)。子どもは 0.78倍、生徒は 0.85倍

### シーンごとに必要な素材(既存14シーン)
リビング・キッチン・寝室・公園・カフェ・学校・スーパー・駅・オフィス・レストラン・ビーチ・街の交差点・ホテル・空港
それぞれ: 背景(遠景)1枚・前景1枚・状態のある設備の各状態

### 第4段階で追加したシーン(24シーン。いまはコードで描いたSVGで作成済み。画像素材への差しかえは未実施)
- 日常: 玄関、バスルーム、病院、薬局、図書館、郵便局
- 旅行: 空港の保安検査、飛行機内、ホテルの客室、観光案内所、地下鉄、レンタカー
- 社会生活: 銀行、洋服店、美容室、映画館、ジム、パーティー
- ビジネス: 会議室、受付、オンライン会議、商談、プレゼンテーション、電話対応

各シーンに必要なもの: 背景1・前景1・登場人物2〜4人(既存の人物の服装ちがいで可)・設備5〜10・小物5〜15
