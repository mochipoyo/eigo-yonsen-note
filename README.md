# えいご4線ノート

英会話ができるようになることと、TOEIC L&R 900点以上を目指す人のための、ブラウザ用の英語学習アプリです。
インストール不要で、PC・スマホのブラウザで動きます。

## できること

- **会話ロールプレイ**(16シーン:旅行 → 日常・雑談 → 仕事 → 会議・交渉)
  1. **キーフレーズ** … 聞いて、まねして、マイクで練習
  2. **ロールプレイ** … 相手のセリフを聞く → 言いたいことに合う返事を3つから選ぶ → 自分の声で言う(音声認識で一致度を表示)
- **文法**(24単元:文の型〜倒置・強調)
  1. **イメージ** … たとえ、要点、発音つき例文、つまずきポイント、会話ですぐ使える1文
  2. **並べかえ** … タイルを並べて英文を組み立てる
  3. **チャレンジ** … TOEIC Part 5 と同じ形の4択 5問(各単元8問からランダム)
- **単語・フレーズ**(約620語、4レベル)… 英→日 / リスニング / 日→英 の3種類の問題と、めくれるカード。正解するたびに次の復習まで間隔が伸びる「記憶の箱」方式(1日 → 3日 → 1週間 → 16日 → 35日)
- **TOEIC形式 演習**(オリジナル問題)… Part 2(40問)、Part 3(10会話)、Part 5(60問)、Part 6(4文書)、Part 7(8文書)。音声はブラウザの読み上げ。形式の説明と学習の考え方つき
- **まちがいノート** … まちがえた文法・Part 2・Part 5 の問題をあとでまとめて復習
- レベル・XP・連続正解ボーナス・1日の目標・きょうのメニュー・単元ごとの星3つ・スタンプ帳
- 設定:発音(アメリカ / イギリス / オーストラリア / カナダ / ミックス)、読み上げ速度、声の選択、日本語訳や英文を隠すリスニングモード、明るい / 暗い表示
- 学習記録はブラウザの localStorage に保存(サーバーには送信しません)

## ファイル構成

```
index.html      公開用のページ(build.py で生成。直接編集しない)
build.py        src/ をまとめて index.html を作るスクリプト
src/
  shell.html    HTML の外枠(メタ情報・ファビコン)
  body.html     タイトル・フォント・CSS・画面の骨組み
  vocab1.js     単語 レベル1・2
  vocab2.js     単語 レベル3・4
  grammar1.js   文法 g01〜g12
  grammar2.js   文法 g13〜g24
  talk.js       会話シーン
  toeic_l.js    Part 2・3
  toeic_r.js    Part 5・6・7
  speech.js     読み上げと音声認識・発話の採点
  core.js       保存・XP・スタンプ・共通部品
  quiz.js       選択問題の共通エンジン
  v_*.js        各画面
  main.js       起動
.nojekyll       GitHub Pages で Jekyll 処理をしないための空ファイル
```

## 編集のしかた

```bash
python3 build.py      # src/ を編集したら index.html を作り直す
```

## GitHub Pages での公開

1. このフォルダを GitHub リポジトリに push する
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 注意

- 音声の読み上げ(speechSynthesis)はほぼすべての最新ブラウザで使えますが、声の種類・質は端末によって異なります。
- 音声認識(SpeechRecognition)は Chrome・Edge・Safari など一部のブラウザのみ対応。ブラウザによっては音声が提供元のサーバーで処理されます。非対応のブラウザでは自己判定ボタンになります。
- レベル区分(〜600 / 600〜730 / 730〜860 / 860〜990)は教材の難しさの目安です。アプリの成績から実際のスコアを予測・保証するものではありません。
