# えいご4線ノート

英会話ができるようになることと、TOEIC L&R 900点以上を目指す人のための、ブラウザ用の英語学習アプリです。
インストール不要で、PC・スマホのブラウザで動きます。

## できること

ホームの「今日のレッスンを始める」を押すだけで、その日の練習が始まります(5・15・30分)。

### 英会話コース(話す・聞く)
- **今日のおまかせレッスン** … 復習 → リスニング → 瞬間英会話 → シャドーイング → 会話クエスト を自動で組み立て。途中で中断・翌日に再開でき、時間が過ぎても打ち切らない
- **瞬間英会話**(144問・9テーマ) … 英語の質問を音声だけで聞き、英語で答える。初級(3択→声に出す)/中級(日本語ヒント)/上級(ヒントなし)/達人(音声のみ・制限時間)。成績で難易度を自動調整
  - 評価は「意味が通じるか」「模範解答との一致度」「反応時間」「ヒントの有無」を分けて表示。一致度は文字起こしの比較で、発音の採点ではない
  - 意味の判定は キーワード・許容表現 による(AIバックエンドを設定した場合はAIでも判定)。聞き違いは「合っていたと思う」で自己申告できる
- **フレーズ復習**(72フレーズ×3場面) … 同じ表現を毎回ちがう場面で思い出して話す間隔反復。翌日→3日→7日→16日→35日を基本に、反応の速さ・ヒント・答えを見たかで調整
- **耳から英語**(102問・4レベル) … 音だけ → 英語の質問 → 英文 → 日本語訳 → もう一度。聞き取れなかった問題は自動で復習へ。別枠で「聞き流し」モード
- **シャドーイング** … A リピート / B シャドーイング / C 録音比較(自分の声とお手本を交互再生)。速さ・くり返し回数・英文/訳の表示切り替え・練習回数・苦手保存。録音は端末内だけで再生し送信しない
- **会話クエスト**(分岐14本+既存の会話シーン16本) … 返事で展開が変わる。各ルートに「自分の言葉で話す」場面があり、それを通ることがクリア条件。4ステージの学習マップ(各ステージ3つクリアで次が開く)
- **AI自由英会話**(任意) … 7人のキャラクター×10の話題。終了後に言い換えの提案。**自分でバックエンドを用意した場合だけ**使える(`backend/` 参照)。未設定でもほかの機能は影響なし
- **苦手リスト** … 言えなかった・遅かった・ヒントを使った英文を自動登録。ヒントなしで3回言えると「克服」
- **テーマ選択** … 日常・旅行・ビジネス・投資/FX・株式市場・AI/テクノロジー・宇宙・科学・音楽/ギター
- 会話ロールプレイ(16シーン・キーフレーズ練習つき)

### TOEIC対策コース
- **文法**(24単元)… イメージ → 並べかえ → チャレンジ(Part 5 形式)
- **単語・フレーズ**(約600語、4レベル)… 見ただけでは箱1まで、選べただけでは箱3まで。日本語から英語を思い出せたときだけ定着(箱4以上)へ
- **TOEIC形式 演習** … Part 2(40問)・Part 3(10会話)・Part 5(60問)・Part 6(4文書)・Part 7(8文書)
- まちがいノート

### 中1〜高3 英語の総復習
- 中1〜高3の56単元(中1〜中3・高1は各10、高2・高3は各8)。各単元は「要点(例文の読み上げつき)→ 確認テスト10問」
- 確認テストは 穴うめ5・並べかえ2・英作文2(話すか入力して答える)・意味1。くわしい解説は文法単元へリンク
- 学年ごとのまとめテスト(20問)、全学年から12問の診断テスト(どの学年から復習するとよいかの目安)
- まちがえた穴うめ・意味の問題は「まちがいノート」、英作文・並べかえは「苦手リスト」へ
- 学年の振り分けは現行の学習指導要領と一般的な教科書の順番にもとづく目安(教科書によって順番は異なる。特に高校)

### うごかす英語ワールド
- 人物や物を動かしながら、英語を感覚的に覚えるモード。12シーン(リビング・キッチン・寝室・公園・カフェ・学校・スーパー・駅・オフィス・レストラン・ビーチ・街の交差点)
- 人物をタップ → 動作メニュー / 人物を選んでから物・人をタップ → 組み合わせの動作 / ドラッグで移動・置く。できない動作はメニューに出ない
- 動作が終わったときに英文カードを表示して読み上げ(現在進行形・状態・過去形、主語を I / You / He / She に切りかえ可能)。英文はテンプレートから作るのでAIなしで動く
- 4つのモード:自由に動かす / 英語を聞いて動かす / 日本語を見て動かして英語で言う / 英語だけ。ミッションごとにシーンは最初の状態にもどる
- 英文をマイフレーズ帳に保存(シャドーイングの「保存した英文」とも共有)。ミッションの成績から苦手な動詞・前置詞を表示

### 記録・分析・続ける仕組み
- 進み具合と苦手分析:リスニング理解度、英文を自力で作る力、反応速度、フレーズ定着率、文法理解度、復習の達成率、ヒントなしの割合(全期間/直近7日)、苦手なテーマ
- 英会話レベルの称号(経験値ではなく話す・聞く実績から判定)、経験値レベル、きょうのクエスト(日替わり3つ)、週間チャレンジ、30日カレンダー、きのうとの比較、スタンプ
- 休んでもペナルティなし(「おかえりなさい」表示のみ)
- 学習記録は localStorage に保存。**設定 → JSONに書き出す/読み込む** でバックアップ・端末の移行ができる
- 記録の形式はバージョン管理(schema 2)。古い記録は自動で移行し、移行前のデータを端末内に控えとして残す。壊れたデータは消さずに退避してから新しく始める

## ファイル構成

```
index.html      公開用のページ(build.py で生成。直接編集しない)
build.py        src/ をまとめて index.html を作るスクリプト
src/
  shell.html    HTML の外枠(メタ情報・ファビコン)
  body.html     タイトル・フォント・CSS・画面の骨組み
  vocab1.js     単語 レベル1・2
  vocab2.js     単語 レベル3・4
  grammar1.js   文法 g01〜g12
  grammar2.js   文法 g13〜g24
  talk.js       会話シーン
  toeic_l.js    Part 2・3
  toeic_r.js    Part 5・6・7
  d_instant.js  瞬間英会話の問題
  d_phrases.js  フレーズと3つの場面
  d_listen.js   耳から英語の問題
  d_quests.js   分岐クエスト
  d_school_*.js 中1〜高3 総復習の単元
  speech.js     読み上げ・音声認識・録音・キーワード判定
  core.js       保存・データ移行・XP・スタンプ・共通部品
  core2.js      学習ログ・分析・日替わりクエスト・バックアップ
  answer.js     声/キーボードで答えるパネルと評価
  ai.js         AIバックエンドの呼び出し(未設定なら無効)
  quiz.js       選択問題の共通エンジン
  w_art.js      ワールドの人物・動物・小物のSVG
  w_fix.js      ワールドの家具・背景のSVG
  w_lang.js     ワールドの英文テンプレート(動詞ごと)
  w_engine.js   ワールドの配置・描画・ドラッグ
  w_act.js      ワールドの動作メニューと動作
  w_scenes.js   ワールドの12シーンとミッション
  v_*.js        各画面(v_school.js が総復習、v_world.js がワールド)
  main.js       起動
backend/        AI会話用バックエンドの例(Cloudflare Workers)。GitHub Pages には不要
.nojekyll       GitHub Pages で Jekyll 処理をしないための空ファイル
```

## 編集のしかた

```bash
python3 build.py      # src/ を編集したら index.html を作り直す
```

## GitHub Pages での公開

1. このフォルダを GitHub リポジトリに push する
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 注意

- 音声の読み上げ(speechSynthesis)はほぼすべての最新ブラウザで使えますが、声の種類・質は端末によって異なります。
- 音声認識(SpeechRecognition)は Chrome・Edge・Safari など一部のブラウザのみ対応。ブラウザによっては音声が提供元のサーバーで処理されます。非対応のブラウザやマイクが使えない場合は、キーボードで答えられます。
- 意味の自動判定はキーワードと許容表現による目安です。自由回答の内容を細かく判定するにはAIバックエンドが必要です。
- レベル区分(〜600 / 600〜730 / 730〜860 / 860〜990)は教材の難しさの目安です。アプリの成績から実際のスコアを予測・保証するものではありません。
